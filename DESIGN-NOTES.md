# Design reference and implementation

This site uses original HTML, CSS, JavaScript, and an original decorative wafer SVG. It has no runtime packages, external font requests, analytics, or copied Cult UI component source.

Visual and interaction references: Cult UI's Expandable pattern (progressive disclosure) and Circuit Board pattern (technical SVG illustration), identified in the official catalog at https://www.cult-ui.com/llms.txt on 2026-11-06. Documentation: https://www.cult-ui.com/docs/components/expandable and https://www.cult-ui.com/docs/components/circuit-board .

This is **Cult UI-inspired**, not an installation of the React/shadcn registry. The lightweight static implementation is suitable for GitHub Pages and works without a build step. Native details/summary elements support keyboard and touch. Project links remain visible without hover or JavaScript. Reduced-motion preferences disable animation. The wafer and signal illustration is decorative, not measured equipment data.

Career dates are supplied by the profile owner. Name, March 2024 SJTU PhD, Scholar URL, and project descriptions are based on the earlier phoenixdyf profile and repository READMEs. No impact metrics or citation counts are asserted. Current account: phoenixsjtu; earlier repositories: phoenixdyf.

Serve this directory with any static HTTP server, for example `python3 -m http.server 8000 --directory site` from the parent directory. Publish the directory contents as the Pages root.
